# Homebrew tap

Homebrew formulae by [MauricioLeon54](https://github.com/MauricioLeon54).

```sh
brew install MauricioLeon54/tap/plugview
```

| Formula | Description |
| --- | --- |
| [plugview](https://github.com/MauricioLeon54/plugview) | Low-latency viewer for HDMI capture cards (Switch, PlayStation, Xbox) |

`Formula/plugview.rb` follows plugview's latest release automatically through the
[Update formula](.github/workflows/update-formula.yml) workflow.
