# Homebrew tap

Homebrew formulae for [plugview](https://plugview.app).

```sh
brew install plugview/tap/plugview
```

| Formula | Description |
| --- | --- |
| [plugview](https://github.com/plugview/plugview) | Low-latency viewer for HDMI capture cards (Switch, PlayStation, Xbox) |

`Formula/plugview.rb` follows plugview's latest release automatically through the
[Update formula](.github/workflows/update-formula.yml) workflow.
